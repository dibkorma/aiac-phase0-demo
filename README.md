# AI Acceleration Club — Phase 0 Demo

> **Una probada gratis de 15 minutos.** No instalas nada: pegas un prompt y tu propio Claude
> se convierte en facilitador.
>
> **Español abajo · English below.**

---

## 🇪🇸 Español

### Qué te llevas en 15 minutos

- **El modelo mental** del sistema, explicado con **tu negocio** como ejemplo — no con uno
  genérico.
- **Un entregable real**: el brief de tu primera herramienta. Un documento corto con el
  problema en tus palabras, qué haría la herramienta, qué datos necesita y el primer paso
  concreto de esta semana.
- **Un mapa honesto** de lo que instala el Phase 0 completo y de lo que este demo no hace.

Es una probada del sistema del club, probado con alumnos en negocios reales — impresión 3D,
bienes raíces, heladerías, construcción, arte.

### Cómo empezar

**Camino A — pegar y listo (cero instalación).** El recomendado.

1. Abre [`DEMO-PROMPT-ES.md`](DEMO-PROMPT-ES.md).
2. Copia todo lo que está debajo de la línea.
3. Pégalo en un chat nuevo en [claude.ai](https://claude.ai) — funciona hasta en el plan
   gratis — y mándalo.
4. Contesta las preguntas. Una a la vez, sin apuro.

*(En inglés es el mismo flujo con [`DEMO-PROMPT.md`](DEMO-PROMPT.md).)*

**Camino B — si ya tienes Claude Code instalado.** Clona esta carpeta y arranca ahí:

```
git clone https://github.com/dibkorma/aiac-phase0-demo.git
cd aiac-phase0-demo
claude
```

Escribe **"Empecemos el demo"** y Claude lee las instrucciones solo. La ventaja: al final te
guarda el brief como un archivo de verdad en tu máquina, en vez de dejarlo en un chat.

### Qué NO es esto

- **No es el programa completo.** No instala nada, no toca tus archivos, no construye una
  herramienta que funcione.
- **No te deja un segundo cerebro, ni un repositorio, ni un router.** Eso es el Phase 0 real.
- **No es una llamada de ventas.** Es el sistema, en pequeño, para que lo sientas antes de
  decidir nada.

### A dónde seguir

Si el brief que te salió se ve como algo que quisieras tener funcionando: el club lo instala
contigo en tu propia máquina — el segundo cerebro, el repositorio, el router y tu primera
herramienta arrancada y probada con tus archivos reales.

Hay varios niveles de acompañamiento, desde correrlo tú solo con la guía hasta un montaje a la
medida. **Habla con tu facilitador del club** para ver cuál te sirve.

## 🇬🇧 English

### What you walk away with in 15 minutes

- **The mental model** of the system, explained with **your business** as the example — not a
  generic one.
- **A real artifact**: the brief for your first tool. A short document with the problem in your
  own words, what the tool would do, what data it needs, and one concrete first step for this
  week.
- **An honest map** of what the full Phase 0 installs, and what this demo does not do.

It's a taste of the club's system, tested with members running real businesses — 3D printing,
real estate, ice cream shops, construction, art.

### How to start

**Path A — paste and go (no install).** The recommended one.

1. Open [`DEMO-PROMPT.md`](DEMO-PROMPT.md).
2. Copy everything below the line.
3. Paste it into a new chat at [claude.ai](https://claude.ai) — works on the free plan — and
   send it.
4. Answer the questions. One at a time, no rush.

*(Spanish is the same flow with [`DEMO-PROMPT-ES.md`](DEMO-PROMPT-ES.md).)*

**Path B — if you already have Claude Code.** Clone this folder and start it there:

```
git clone https://github.com/dibkorma/aiac-phase0-demo.git
cd aiac-phase0-demo
claude
```

Type **"Let's start the demo"** and Claude reads the instructions on its own. The upside: at the
end it saves your brief as a real file on your machine instead of leaving it in a chat.

### What this is not

- **It is not the full program.** It installs nothing, touches none of your files, and builds no
  working tool.
- **It leaves you no second brain, no repository, no router.** That's the real Phase 0.
- **It is not a sales call.** It's the system in miniature, so you can feel it before deciding
  anything.

### Where to go next

If the brief you end up with looks like something you'd want running: the club installs it with
you on your own machine — the second brain, the repository, the router, and your first tool
started and tested against your real files.

There are several levels of support, from running it yourself with the guide to a custom build.
**Talk to your club facilitator** to find out which one fits.
